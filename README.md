Little-endian записывает младшие байты в младшие ячейки,а большие в большие.

ABC) 3/3|41-42-43

Привет) 6/12|D0-9F-D1-80-D0-B8-D0-B2-D0-B5-D1-82

Разное количество байтов и символов в слове обусловлено кодировкой. Под каждый символ в кодировке выделено разное количество байт. 

rus А) D0-90

eng A) 41

4. Написание байтов в формате little-endian.
5. Зависит от формата записи. Big-endian либо little-endian.

8. Чтобы сохранить запись в string.
